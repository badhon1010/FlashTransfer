# FlashTransfer

FlashTransfer is a modern, fast, reliable, secure, cross-platform file-transfer application. It is designed to transfer files directly between nearby devices over a local network with high speed, strong reliability, resumable transfers, file-integrity verification, secure pairing, and multi-device support.

## Architecture
FlashTransfer uses:
- **Frontend**: React + TypeScript + Vite
- **Desktop Framework**: Tauri
- **Backend / Core Engine**: Rust

For more information, see [docs/architecture.md](docs/architecture.md).
